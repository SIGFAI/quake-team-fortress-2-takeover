# Team Fortress 2 Takeover

**Quake** × Team Fortress 2 · visual · idea by the team

Bring Team Fortress 2 into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I dropped RED team from Team Fortress 2 into Quake: Heavy, Scout, Soldier and Pyro with crits, flames, a sentry, and hats everywhere.

## Install

Copy the mod folder into your Quake folder next to id1 and start Quake with -game followed by the mod folder name. Type impulse 50 in the console to build a sentry gun, then fight the RED mercenaries.
